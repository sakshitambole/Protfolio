🌐 Personal Portfolio Website

📌 About the Project

This is a personal portfolio website developed using HTML5 and CSS3 to showcase my personal information, technical skills, projects, resume, and contact details.

The website provides a simple and professional way to present my profile and demonstrate my web development skills.

🎯 Objectives

- Create a professional personal portfolio website.
- Showcase my technical skills and projects.
- Provide a downloadable resume in PDF format.
- Display contact information.
- Build a responsive and user-friendly website.

🛠️ Technologies Used

- HTML5 – To structure the website.
- CSS3 – To style and design the website.
- Visual Studio Code – For development.

✨ Features

- Home Section: Introduction and welcome message.
- About Me: Personal introduction and profile photo.
- Skills Section: Displays technical skills.
- Projects Section: Showcases my projects.
- Resume Section: Allows visitors to download my resume in PDF format.
- Contact Section: Displays contact information.
- Responsive Design: Adapts the layout to different screen sizes.
- Navigation Menu: Allows visitors to navigate between sections.

⚙️ How to Run the Project

Follow these steps to run the website on your computer.

1. Install Visual Studio Code.
2. Create a folder named "Personal-Portfolio".
3. Add the "index.html" and "style.css" files.
4. Add your profile photo as "profile.jpg".
5. Add your resume PDF as "resume.pdf".
6. Open the project folder in Visual Studio Code.
7. Open "index.html" in a web browser.

Optional: Install the Live Server extension in VS Code, right-click "index.html", and select Open with Live Server.

📄 Resume Download

The website provides a resume download button.

The HTML code used is:

<a href="resume.pdf" download class="btn">
    Download My Resume
</a>

Ensure that "resume.pdf" is located in the same directory as "index.html".

📱 Responsive Design

The website uses CSS media queries to adapt its layout to different screen sizes, including desktop computers, tablets, and mobile devices.
